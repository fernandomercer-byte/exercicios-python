## Descrição

Repositório com a lista de 25 exercícios de Python da atividade avaliativa. Os exercícios estão divididos em cinco partes: variáveis, condicionais, `while`, `for` e listas.

## Tecnologia utilizada

- **Linguagem:** Python 3 (versão: conferir com `python --version`)

## Como executar

1. Instale o Python 3.
2. Abra o terminal na pasta do repositório.
3. Rode o arquivo desejado, por exemplo:

```
python parte1-variaveis/ex01.py
```

## Índice dos exercícios

### Parte 1 — Variáveis, entrada e saída
- `ex01.py` — Exibe nome e idade guardados em variáveis.
- `ex02.py` — Soma dois números digitados.
- `ex03.py` — Calcula a área de um círculo a partir do raio.
- `ex04.py` — Converte Celsius para Fahrenheit.
- `ex05.py` — Calcula o valor total de uma compra com duas casas decimais.

### Parte 2 — Condicionais
- `ex06.py` — Informa se o número é par ou ímpar.
- `ex07.py` — Mostra o maior de dois números ou informa se são iguais.
- `ex08.py` — Informa se o número é positivo, negativo ou zero.
- `ex09.py` — Classifica a média em Aprovado, Recuperação ou Reprovado.
- `ex10.py` — Informa se a pessoa já pode votar (mínimo 16 anos).

### Parte 3 — Repetição com while
- `ex11.py` — Exibe os números de 1 a 10.
- `ex12.py` — Soma números até digitar 0.
- `ex13.py` — Pede a senha até acertar `senai123`.
- `ex14.py` — Exibe a tabuada de um número.
- `ex15.py` — Conta os números positivos digitados até o 0.

### Parte 4 — Repetição com for
- `ex16.py` — Exibe os números de 1 a 20.
- `ex17.py` — Exibe os pares de 2 a 20.
- `ex18.py` — Soma os números de 1 a 100.
- `ex19.py` — Calcula o fatorial de um número.
- `ex20.py` — Contagem regressiva de 10 a 1 e "Fim".

### Parte 5 — Listas
- `ex21.py` — Exibe cada item de uma lista de cinco números.
- `ex22.py` — Soma os itens da lista.
- `ex23.py` — Encontra o maior valor da lista.
- `ex24.py` — Conta os itens maiores que 10.
- `ex25.py` — Exibe a lista na ordem inversa.

## Explicação do .gitignore

- `__pycache__/` — cache criado pelo Python ao executar os programas.
- `*.pyc` — arquivos compilados gerados automaticamente.
- `venv/` e `.venv/` — ambiente virtual, pesado e específico de cada computador.
- `.vscode/` — configurações pessoais do editor.
